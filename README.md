# t-field Effective Field Theory (EFT) Framework: Paper 2

This repository contains the complete Python code used to generate all numerical results and figures (Figures 1 to 8) for the paper:

**"Phenomenological Analysis of Nuclear Mass Residuals and a Speculative Early-Universe Dark Photon Condensate in the t-Field Framework"**

## Repository Structure

*   `fig1_nuclear_residuals.py`:
    Calculates the residuals of 58 nuclear masses based on the liquid drop model and generates Figure 1 (Residuals with magic number markers and proton number color map).
*   `fig2_to_8_dark_matter_analysis.py`:
    Contains the analysis for the early-universe dark photon BEC mechanism. It generates Figures 2 through 8, including:
    *   Dark photon parameter space (Figure 2)
    *   Redshift of BEC formation (Figure 3)
    *   Jeans mass stability (Figure 4)
    *   BEC core vs. NFW cusp (Figure 5)
    *   Galactic rotation curves (Figure 6)
    *   EFT extrapolation to superheavy nuclei (Figure 7)
    *   Neutron star tidal deformability (Figure 8)

## Requirements

The scripts are written in Python 3. It is recommended to use the following libraries:
*   `numpy`
*   `scipy`
*   `matplotlib`

## Usage

Run the scripts directly in your Python environment. The plots will be generated and displayed (or saved locally, depending on your matplotlib configuration).
